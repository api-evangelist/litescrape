Litescrape is a search-results and web-data API from Litescrape LLC (Sheridan, Wyoming) that returns structured JSON from Google Search, Google AI Overview and AI Mode, Google Maps and reviews, Google Shopping, Bing, DuckDuckGo, Apple Maps, Yelp, Tripadvisor, Google Play and the Apple App Store, plus a browser-rendered Fetch and Screenshot API, billed at a flat $0.15 per 1,000 requests on prepaid credits with no subscription. It ships Python and TypeScript SDKs, an n8n node, a hosted MCP server at mcp.litescrape.com with a free keyless allowance, and a ZeroClick agent storefront at agents.litescrape.com that publishes its OpenAPI.

**Areas:** Company · SERP · Web Scraping · Search · Google Maps · Reviews · Web Data · MCP
